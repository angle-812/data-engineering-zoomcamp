在浏览器外动手：Rocky Linux

学习台的命令要真的敲一遍才有用。这台机器上已经有一台 Rocky Linux，FinalShell 里也存好了连接。

三步进入

  1. 双击桌面 启动 Linux 环境：它会先看虚拟机开没开，没开就开机，等 SSH 通了再唤起 FinalShell。
  2. 在 FinalShell 左侧点 rocky 这个连接。
  3. 照右侧「练习」里的命令敲，每张命令卡右上角有复制按钮。

连不上时按这个顺序查

  • ip a 在虚拟机里看 IP 变没变（NAT 模式重启后可能变），变了就改 FinalShell 里的主机地址。
  • 虚拟机里执行 sudo systemctl status sshd，没起来就 sudo systemctl start sshd。
  • 宿主机 ping 192.168.100.129 不通 → 多半是 VMware 的虚拟网卡被禁用，到「网络连接」里把 VMnet8 启用。
