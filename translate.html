看英文视频和讲义：翻译方案

先回答两个问题

① 视频能在浏览器里看吗？

能，而且只能在浏览器里看。打开这个地址就是播放器：

https://angle-812.github.io/data-engineering-zoomcamp/player.html

桌面那个 player.html 双击打不开视频，不是你操作错了——YouTube 现在要求嵌入的页面必须有 http(s) 来源，file:// 打开的一律拒绝（错误 153）。所以：看视频用网址，桌面那份用来读离线讲义。

② 翻译插件装哪个？

装 沉浸式翻译（Immersive Translate） 一个就够。它同时解决两件事：

  • YouTube 视频 → 原文 + 中文双语字幕同时显示
  • 讲义网页（英文 Markdown）→ 中英对照排版，不是把原文替换掉

一、安装（2 分钟）

走 Edge 商店（推荐，国内能打开）

  1. 用 Edge 打开：https://microsoftedge.microsoft.com/addons/
  2. 搜索框输入 沉浸式翻译
  3. 找到图标是蓝底白色「文/A」的那个（发布者 Immersive Translate），点 获取
  4. 弹窗点 添加扩展
  5. 装好后点浏览器右上角的拼图图标 🧩，把「沉浸式翻译」后面的眼睛/图钉点亮，让它常驻在工具栏

如果商店打不开，两个备用办法

  • 官网下载页：https://immersivetranslate.com → Download → 选 Edge / Chrome，会带你到对应商店或给离线包
  • 油猴脚本：你之前装过 Tampermonkey，直接用它装官方的油猴版脚本（官网下载页有入口）

⚠️ 只在官方商店或官网装。搜索引擎广告位里的「沉浸式翻译下载」有一半是套壳，会偷浏览器数据。

二、场景 A：YouTube 看课时开双语字幕

装好之后，直接打开播放页，字幕会自动变成两行：英文在上、中文在下。

没出现的话按顺序查这三处：

  1. 这个视频有没有字幕轨 播放器右下角齿轮 ⚙ → 字幕 → 看有没有 English (auto-generated)。有就选上。 （YouTube 会自动生成英文字幕，这个课的视频基本都有）
  2. 扩展的字幕开关 点扩展图标 → 更多功能 → 打开「字幕翻译」（有的版本叫「当前网站字幕翻译」）
  3. 刷新一次页面，再等两三秒

字幕样式：鼠标移到画面上，会出现扩展的浮动按钮，可以切换「双语对照 / 仅译文」、调字号和颜色、把字幕位置往上挪（不挡画面底部）。

重要提醒：双语字幕是边播边翻，中文会晚半句。术语（orchestration、idempotent、watermark 这类）机翻经常不准，看的时候眼睛扫一眼上面那行英文，比死磕中文快。

三、场景 B：讲义网页中英对照读

课程讲义全是英文 Markdown。三种打开方式，翻译体验不一样：

怎么打开 翻译效果
看板里点「原文」（跳 GitHub） 点扩展图标 → 翻译，整页变中英对照
看板上点「打开」（本地 HTML） 同上，本地文件也能翻
直接拖 PDF 进浏览器 支持，会保留原排版，公式和表格不会乱

让它自动翻：在讲义页面点扩展图标 → 选「始终翻译此网站」，以后打开 github.com 或本地 HTML 就自动翻，不用每次点。

读 PDF 更省事的做法：把 PDF 拖进浏览器窗口 → 右键 → 用沉浸式翻译打开（或点扩展图标里的「翻译 PDF」）。扫描版也能识别，但慢一点。

四、场景 C：不想装扩展的兜底方案

Edge 自带翻译：打开英文页面 → 地址栏右边出现翻译图标 → 点它 → 「翻译成中文」。 优点：零安装。缺点：整页替换成中文，原文消失；不支持视频字幕。

所以：只看讲义可以用它，要字幕还是得装插件。

五、想「边看边学」的话，再加一个（可选）

Language Reactor（Chrome / Edge 商店都有）：为学语言设计的。

  • 双语字幕 + 点单词立刻出词典
  • 字幕逐句自动暂停，一句听懂再往下（练听力很有用）
  • 有生词本，能导出到 Anki
  • 免费版够用；Pro（约 5 美元/月）才能无限存词、AI 语法解释

它和沉浸式翻译可以共存，但别同时开，两套字幕会叠在一起。看技术课用沉浸式翻译，专门练听力时换 Language Reactor。

六、几个实用细节

手机上看 浏览器扩展在手机上没有。手机方案：装沉浸式翻译的手机 App（iOS / Android 都有），或直接用手机浏览器打开播放页 + 用浏览器自带翻译看讲义。视频字幕在手机 YouTube App 里没法双语，只能开 YouTube 自带的「自动翻译」字幕。

中文自动翻译质量 YouTube 自带的「设置 → 字幕 → 自动翻译 → 中文（简体）」也能用，但它是逐词机翻，读起来很硬。沉浸式翻译是按整句翻，通顺程度高一档——这是装插件最实际的理由。

别做的事 - 别在插件里填 GitHub 密码。只有需要 AI 引擎（DeepSeek / OpenAI / Gemini）时才填那家的 API Key，而且那是另一件事，跟 GitHub 无关 - 别装「破解版 / 绿色版」扩展 - 别一次装五六个翻译插件，互相抢页面，反而更卡

一句话总结

Edge 商店装「沉浸式翻译」→ 打开播放页看双语字幕 → 讲义页点一下翻译。 视频只在浏览器看：https://angle-812.github.io/data-engineering-zoomcamp/player.html
