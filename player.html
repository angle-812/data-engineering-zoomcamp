视频中英双字幕怎么开

课程视频是英文的，官方字幕也是英文。要中文，靠「沉浸式翻译」官方版扩展——它能给 YouTube 叠一层双语字幕。

先确认装的是正版

Edge 商店里有两个同名扩展。正版开发者是 Immersive Translate（400 万+ 用户，设置页里有「视频字幕」一节）；另一个是个人开发者的精简版，设置页只有 DeepL / OpenAI 密钥和 OCR 识别，没有视频字幕功能，装它等于白装。判断方法：点扩展图标 → 设置，看到「视频字幕」就是正版。

去 Edge 商店装正版

装好后三处设置

  1. 点扩展图标，弹窗顶部确认 目标语言 = 中文（简体），翻译服务选 微软翻译（免费，不需要填任何 Key）。
  2. 进 设置 → 左侧 视频字幕 → 打开「启用字幕翻译」，显示方式选 双语，字号按自己舒服调。
  3. 装完把旧的同名扩展删掉（地址栏输 edge://extensions），两个一起开会把同一段话翻两遍。

设完回播放页刷新一次，播放时字幕位置会出现两行。

不想装扩展的替代方案

  • YouTube 自带字幕：播放器右下角 CC → 设置 → 字幕 → 自动翻译 → 中文（只有中文，不是双语）。
  • 学习台右栏讲义点 中英对照，原文下面加中文——视频听不懂时看讲义往往更快。

为什么不能在这里直接给你双语字幕

视频跑在 YouTube 的 iframe 里，字幕轨道在它的域内，外面的页面拿不到文本，也就没法自己翻译再叠上去。这是浏览器的同源限制，不是没做。

讲义那边不依赖扩展：点右栏的「中英对照」，用的是浏览器内置翻译引擎，翻完存在本机，下次打开直接读缓存。
